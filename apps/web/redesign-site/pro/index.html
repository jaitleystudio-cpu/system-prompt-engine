Features

01Prompt Studio Preview

Shape intent into a prompt you can read, check and reuse.

  • Build in blocks: role, rules, tone, output format, examples and your own requirements.
  • Static checks flag a missing role or format, conflicting rules and unfilled {{variables}}, labelled as checks, not quality scores.
  • Save versions, diff them, and import or export portable .spe files.
Open Prompt Studio →

02Agent Blueprint Preview

Design the team before you write the code.

  • Lay out agents, the tools each may use, step limits and who hands off to whom.
  • Checks catch duplicate names, broken handoffs and risky tools without human approval.
  • Export a draft config in MCP-, OpenAI- or Anthropic-style JSON.
Open Agent Blueprint →

03Regression Lab Preview

Know what a prompt change fixed, and what it broke.

  • Write test cases once: must include, must not include, format and length.
  • Run version A and version B side by side and see fixed, broken and unchanged cases.
  • The demo runner in this preview is simulated, and it is labelled that way.
Open Regression Lab →

04Signed Releases Preview

Ship prompts anyone can verify.

  • Give a prompt a version and changelog, then sign it with Ed25519 in your browser.
  • Anyone can paste the pack and check it has not been changed since signing.
  • Private keys are generated in the tab and never saved or sent.
Open Signed Releases →
