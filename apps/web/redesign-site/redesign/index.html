FAQ

Good questions.

Is SPE free?

Yes. The core engine is free to use without an account.

Does SPE send my prompts to a server?

The core engine runs in your browser. Some optional features may work differently; each one says so where it applies.

Which AI tools does the output work with?

The result is plain text, so you can paste it into any chat assistant or API that accepts a system prompt.

Do I need to know prompt engineering?

No. Write the way you'd brief a colleague. SPE adds the structure.
