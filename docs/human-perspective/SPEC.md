# SPE Human Perspective Layer

## Mission and boundary
Apply the two supplied language papers as a shared presentation contract. Preserve product facts, user-authored text, generated professional prompts and K0/K3 ownership. No paid model, remote judge, profile inference or analytics. Deterministic rules identify language risks; they cannot measure human feelings or establish universal cultural appropriateness.

## Architecture
Canonical meaning and claim references → audience/surface/depth → curated candidate → deterministic risk review → surface adapter. Types: CopyIntent, AudienceContext, CopyCandidate, InterpretationReview, SurfaceCopy. Depths: EXPERIENCE, PRODUCT, INSPECT, PROOF. English is the reviewed source locale. Unsupported locales fall back explicitly to English; no automatic translation claim.

Web consumes shared copy; mobile, desktop, extension and AI/coding-plugin profiles reuse the same contract. Adapter fixtures do not imply those products exist. Hero variants use explicit template selection or a completed action in this session, never inferred personality, tracking or a visitor profile. No timer-driven headline rotation.

## Truth corrections to source examples
Do not claim automatic understanding, gap filling, perfect preservation, measured superiority, daily new content, universal compatibility or a production qualification. Use truthful activity labels corresponding to actual worker phases. Error recovery says the brief remains in the current page, not that it is permanently saved. Integrity failures stop generation and keep precise diagnostics available. Private hosting can require sign-in even though core prompt preparation has no mandatory provider; do not claim the entire hosted site has no account requirement.

## Acceptance and evidence plan
1. Golden fixtures for hero, returning, mobile, extension, plugin, privacy, recovery and proof.
2. Adversarial cases for unsupported superiority, 10x claims, flattery, jargon and infrastructure framing; technical terms remain allowed at appropriate depths.
3. Build-time visible-copy inventory with checked-in editorial review records; unknown/changed public copy fails the gate. Source additions cannot silently bypass the inventory.
4. Real-WASM output regression unchanged: UI language must not rewrite generated prompts or affect decisions.
5. Browser checks for hero, preparation, completion, error details and editing on desktop/mobile.
6. Report rule-check results separately from human-language research, accessibility certification and independent visual evaluation.

## Interpretation review
For each surface consider first-time/returning visitors, non-native English speakers, creators, developers, business users, skeptical AI experts, privacy-conscious people, mobile users and screen-reader users. Editorial assessments anticipate interpretation; they are not participant studies. New locale release requires a competent language reviewer for meaning, idiom, formality, metaphor, action and line length.

## Implementation order
Freeze constitution → schemas and voice contract → risk rules and curated hero library → shared surface adapters → website integration and contextual diagnostics → golden/adversarial tests → build gate → browser review → publish. Existing frozen study files remain untouched.
