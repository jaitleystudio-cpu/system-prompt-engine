# SPE-WEB-03 Originality Review

## Review scope

This review tests the Semantic Forge and Semantic Observatory concepts against the user's rejection list, the supplied image references, common AI-product patterns, and the present WEB-02 implementation.

## Concept provenance

The concept is derived from SPE's actual transformation:

`raw request → semantic meaning → structure → strategy → rendered prompt → portable .spe artifact`

The core object is therefore a changing longitudinal workpiece. This is a product-specific consequence, not a decorative symbol chosen from the usual AI visual library.

## Distance from WEB-02

| WEB-02 pattern | WEB-03 decision |
|---|---|
| Central crystal/octahedron | No nucleus; an off-axis longitudinal workpiece |
| Three orbital rings | Linear rails, indexing gates, tensioners, and folding planes |
| Cyan/amber emissive palette | Graphite, titanium, ceramic, scarce warm metal, muted semantic hues |
| Floating capability cards | Capabilities emerge as labeled transformations in one scene |
| Centered hero wordmark | Left-weighted editorial identity and integrated intake composer |
| Glass-card section stack | Continuous spatial acts with DOM annotations |
| Generic constellation/orb | Portable layered folio |
| Serif display headings | Precise sans editorial typography |
| Desktop shrunk for mobile | Independently composed portrait cutaway |

Result: WEB-03 is not a restyle of WEB-02. It changes metaphor, topology, pacing, typography, color behavior, and information architecture.

## Semantic originality test

Each visual element must answer a product question:

- Why is this filament this color? It represents a named semantic category.
- Why is a span open? The information is unknown/unresolved.
- Why does a gate stop movement? It represents a constraint.
- Why can a path bend? A preference guides but does not obligate.
- Why does the warm spine appear later? Strategy sequences already-extracted meaning.
- Why is the final form layered? `.spe` carries intent, requirements, strategy, prompt, and lineage.

If an element cannot answer a product question, it is atmosphere and must survive a scarcity test. Most decorative particles, circuit lines, symbols, and floating glyphs will fail.

## Brand originality risks

1. **Industrial-forge cliché**
   - Risk: anvils, sparks, flames, molten metal, and steampunk machinery.
   - Control: the forge is a precision semantic press: clean rails, material tension, low-temperature warm light, no literal blacksmith imagery.

2. **Luxury automotive CGI**
   - Risk: titanium/ceramic surfaces and dramatic rim light can resemble a car configurator.
   - Control: semantic labels and data-bound transformation remain continuously visible; no pedestal product reveal.

3. **Sci-fi terminal**
   - Risk: uppercase mono labels, dark surfaces, and 3D depth can become gaming/cyberpunk.
   - Control: use editorial sans typography, daylight ceramic highlights, sparse mono, no scanlines/HUD reticles/neon bloom.

4. **AI pipeline diagram**
   - Risk: filaments and stages can flatten into a familiar node graph.
   - Control: use one changing material workpiece and physical relationships, not circles connected by lines.

5. **Generic productivity dashboard**
   - Risk: workspace lenses can become cards, tabs, and metric tiles.
   - Control: one central workbench, edge-mounted instruments, a material drawer for history, and no KPI region.

## Truthfulness audit

Allowed only when sourced from current runtime state:

- local worker/WASM compile path,
- current compile stage,
- worker/WASM errors,
- online/offline shell condition,
- envelope privacy fields,
- `.spe` artifact availability and lineage,
- hash/import count when present,
- opt-in local history status,
- selected target/category,
- no TypeScript fallback.

Disallowed:

- “verified” without defining the actual runtime check,
- completeness or quality scores,
- confidence percentages,
- prompt improvement percentages,
- proof badges,
- certifications,
- customer/provider counts,
- unsupported “private by design” generalizations,
- “production ready.”

## Logo condition

No durable logo asset has been selected in this design stage. The two supplied images are temporary references and must not be promoted to Brand Assets. Therefore:

- Variations use the full text wordmark `SYSTEM PROMPT ENGINE`.
- They must not invent `SPE` initials inside a placeholder badge, an emoji, a generic glyph, or a new SVG mark.
- The mandatory current-UI reproduction may reflect the actual source component because its purpose is ground-truth capture, not new identity creation.
- If a real logo is selected later, it must be uploaded as a Brand Asset, passed as a reference, and structurally verified in every logo position.

## Direction comparison

### A — Semantic Forge

- Strongest product metaphor and cinematic impact.
- Best explanation of constraints, unknowns, and strategy as different physical roles.
- Highest art-direction burden; must avoid literal machinery.
- Recommended as the lead direction.

### B — Semantic Observatory

- Strongest editorial readability and semantic comparison.
- Lower risk for responsive and reduced-motion execution.
- Less visceral transformation; may feel like an advanced data essay if the integrated composer is not dominant.
- Recommended as the contrast direction, not a fallback dashboard.

## Review verdict

Both directions pass the forbidden-form audit and are sufficiently separated from WEB-02 and the supplied images. Direction A has the clearest ownable identity for SPE because the visual grammar is derived from the product's semantic transformation. Direction B is distinct enough to compare meaningfully while sharing the same original brand system.
