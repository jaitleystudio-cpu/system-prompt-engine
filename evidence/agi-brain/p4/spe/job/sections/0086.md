## Introduction to Cross-Validation Methods

Cross-validation is an essential technique in machine learning that involves partitioning the dataset into multiple subsets or "folds." The primary goal of cross-validation is to ensure that models are not only trained but also validated under various conditions and scenarios. This method helps prevent overfitting by assessing how well a model can generalize to new, unseen data.

### Types of Cross-Validation

Cross-validation methods can be broadly categorized into two types: **train-test split** and **bootstrapping**.

1. **Train-Test Split**: In this approach, the dataset is divided into training and testing sets. The model is trained on the training set and then validated using the testing set to evaluate its performance.
   
   ```plaintext
   # Example of train-test split
   X_train, X_test = train_test_split(X, test_size=0.2)
   y_train, y_test = train_test_split(y, test_size=0.2)
   ```

2. **Bootstrapping**: Bootstrapping involves resampling the dataset with replacement to create multiple subsamples or "bootstrap samples." Each bootstrap sample is then used as a training set and validated against the remaining data.

   ```plaintext
   # Example of bootstrapping
   from sklearn.utils import resample

   n_bootstrap_samples = 50
   ```

## Cross-Validation Techniques within Validation Procedures

### 9.7.1 Holdout Method

The holdout method involves splitting the data into a fixed number of folds or subsets. A fraction of these folds is used as the test set, while the remaining folds are used for training.

```plaintext
# Example of holdout method
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
```

### 9.7.2 K-Fold Cross-Validation

K-fold cross-validation divides the dataset into k equally sized folds or subsets.

```plaintext
# Example of k-fold cross-validation
from sklearn.model_selection import StratifiedKFold

k = 5
kf = StratifiedKFold(n_splits=k, shuffle=True)

for train_index, test_index in kf.split(X):
    X_train, X_test = X[train_index], X[test_index]
    y_train, y_test = y[train_index], y[test_index]
```

### 9.7.3 Leave-One-Out Cross-Validation (LOOCV)

Leave-one-out cross-validation is a simple form of k-fold cross-validation where the data is split into n folds, with each fold containing one instance.

```plaintext
# Example of LOOCV
from sklearn.model_selection import LeaveOneOut

loo = LeaveOneOut()
for train_index in loo.split(X):
    X_train, X_test = X[train_index], X[~train_index]
    y_train, y_test = y[train_index], y[~train_index]
```

### 9.7.4 Stratified Cross-Validation

Stratified cross-validation ensures that the folds are balanced across categories or classes.

```plaintext
# Example of stratified cross-validation
from sklearn.model_selection import StratifiedKFold, strata_split

strat_kf = StratifiedKFold(n_splits=k, shuffle=True)
for train_index, test_index in strat_kf.split(X):
    X_train, X_test = X[train_index], X[test_index]
    y_train, y_test = y[train_index], y[test_index]

```
