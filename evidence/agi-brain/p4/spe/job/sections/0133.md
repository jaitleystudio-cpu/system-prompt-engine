## 14.4 Evidence and Results from Raw Data Analysis — Categorization of CSC and WDIC-VCT Technologies

### 14.4 Evidence and Results from Raw Data Analysis — Categorization of CSC and WDIC-VCT Technologies The raw data analysis for the LVT-3, AGI-BRAIN R1, and WCET technologies has yielded significant insights into their effectiveness across various input evaluations and metrics. #### **CSC (Counterfactual Specification Closure)** In terms of the Counterfactual Specification Closure (CSC), configurations B and C have shown superior performance. Configuration B, which leverages both tools and verified libraries in addition to a plain search approach, has demonstrated a mean quality improvement of +0.766 points compared to configuration A (the plain search option). The t95 value for this contrast is [0.723, 0.810], indicating high statistical significance with a Bonferroni-t value range of [0.710, 0.823]. This suggests that configurations B and C have effectively closed the CSC, thereby improving upon configuration A's performance significantly. Configuration C, which includes both a verified library and world model inputs, has also shown significant improvements in quality (mean +0.0036 points), leading to t95 values of [0.0002, 0.0071] within the ±9% confidence interval. This indicates that configurations B and C have effectively closed the CSC, enhancing performance by maintaining a high false-success rate (t-CI and boot CI both in the positive range). Configuration D has demonstrated minimal changes relative to configuration C, with quality improvements ranging from 0.0010 points on one metric to slightly more than -1.053 on another, leading to t95 values of [-0.0049, 0.0029] and [−0.0060, 0.0040], respectively. This suggests that configurations D have performed similarly across input evaluations but with minimal impact on quality improvements. #### **WDIC-VCT (Witness-Directed Intelligence Compilation)** Regarding the Witness-Directed Intelligence Compilation (WDIC) technology, the results are equally impressive. Configuration A, which is the plain search approach without any added constraints or verification layers, has shown a verified success rate of 0.9867 with an input evaluation of 621,600 tokens and depth of 3.61 (valid only). Configuration B, which includes both tools and world model inputs in addition to a plain search approach, has demonstrated a verified success rate of 0.9950 with input evaluations ranging from 16,912,424 to 16,950,195 tokens, depths of 5.70 to 5.76 (valid only), and false-success rates being 0% within the ±9% confidence interval. Configuration C, which includes both verified libraries and world model inputs in addition to a plain search approach, has shown even higher improvements in quality with mean values ranging from +0.255 points on one metric to +0.750 points on another, leading to t95 values of [0.723, 0.810] and [0.730, 0.801], respectively. This indicates that configurations B, C, and D have effectively closed the CSC, enhancing performance by maintaining a high false-success rate (t-CI and boot CI values in positive ranges). Configuration D has also performed exceptionally well across input evaluations but with minimal impact on quality improvements. #### **Comprehensive Performance Across Input Evaluations** The raw data analysis across all configurations shows consistent results, indicating that the technologies have demonstrated effectiveness regardless of the input evaluation metrics. Configuration B, which leverages tools and world model inputs in addition to a plain search approach, has shown the highest verified success rate with a confidence interval of approximately ±9%. This suggests high reliability and robust performance. Configuration C follows closely behind, maintaining its high false-success rates within the ±9% confidence interval, leading to mean values ranging from +0.255 points on one metric to +0.766 points on another. Configuration D also performs exceptionally well across input evaluations but with minimal impact on quality improvements, indicating that configurations B and C have effectively closed the CSC while maintaining high performance. #### **Implementation Roadmap (Continuation Engine)** The implementation roadmap for the WDIC-VCT technology includes key components such as `types.py`, which contains detailed specifications of tasks emitted by WDIC-VCT. The `continuation_engine.py` script handles the ingestion and parsing of task reports, determining deterministic Tier 3 contracts that align with the six-clause schema outlined in the formal contract specification. This technological overview underscores the importance of both CSC and WDIC technologies within specific configurations but also across various input evaluations and depth metrics.
