# Hero revision reasoning and evidence

1. Mission: fix the rejected home hero only; improve visual hierarchy, plain language, daily variation and accessible motion.
2. Decomposition: custody; original composition; hero code; copy; date logic; responsive art; motion; tests; evidence; scope.
3. Evidence plan: baseline captures, rendered comparisons, 31-title fit matrix, date tests, axe, runtime/resource checks and unchanged-scope assertions.
4. Foundations: existing SPE visual direction, founder storyboard, current theme contract, native CSS transitions and semantic HTML.
5. Current reference: Norrly used only for motion/clarity/live-preview patterns in the preceding review. An Awwwards result exposed the familiar design/usability/creativity/content criteria, but direct official evaluation pages timed out. No claim of current rulebook verification or 100% compliance.
6. Contrary evidence: the founder rejected the previous result. Automated passes did not establish aesthetic success.
7. Benchmark evidence: the original static PNG and rejected grid are retained as distinct baselines.
8. Source interrogation: read the complete hero implementation, stylesheet, date hook, tests, visual-direction notes and relevant Product Design plugin instructions.
9. Method verification: deterministic local-calendar math, DST-aware midnight scheduling, no external service or provider changes, native DOM motion.
10. Claims and evidence: daily change → unit tests plus browser clock; accessible static alternative → axe plus semantic DOM; native artwork → no image/canvas/request assertions; scope → byte/object comparisons; measured weight → bundle and browser resource records.
11. Contradictions: premium visual ambition versus limited asset weight; original horizontal art versus narrow phones; detailed prompts versus simple website copy. Resolve with a single native scene, vertical phone composition and a strict split between website copy and prompt logic.
12. Unknowns: founder aesthetic acceptance, worldwide comprehension, physical low-end performance, independent award assessment, existing release-WASM packaging failure.
13. Options considered: static PNG; autoplay video; Three.js sculpture; canvas particles; neon reactor; five equal cards; scroll-only sequence; looping timeline; native layered storyboard; typography-only hero; all-at-once infographic; daily randomly generated headings.
14. Elimination: PNG/video conflict with the native live-story task; Three.js/canvas add unnecessary machinery; reactor violates palette; card grid repeats rejected structure; scroll-only hides meaning; endless loop distracts; typography-only removes required story; random headings are unstable and unreviewed.
15. Surviving option: native layered storyboard with one finite sequence, direct step controls, semantic equivalent, final-state fallback and deterministic reviewed daily copy.
16. Decision with uncertainty: implement and measure this option; reserve aesthetic approval for the founder.
17. Prototype: render on local preview. First comparison found text overlap, long headline wrapping and mobile page/caption collision.
18. Measured correction: shorter selected headline, reduced display size, opaque meaning plane, separated source document, taller mobile scene; the final responsive and date matrix passes.
19. Independent check: separate pure date tests and actual-browser clock tests, copy inventory review, axe, visual comparison and scope assertions. This is not an independent human design review.
20. Integration: hero-only commit; the founder subsequently authorized a push to the existing PR branch. No hosting, deployment or integration into frozen product areas.

Skills/plugins applied: Product Design audit, image-to-code interpretation and design-QA workflows; Codex app/browser tools for local review. The user’s explicit native-animation requirement overrides the skill’s generic preference for reusing image assets. Existing founder art and detailed instructions provide the chosen design target; no unnecessary design-selection or hosting flow was introduced.
