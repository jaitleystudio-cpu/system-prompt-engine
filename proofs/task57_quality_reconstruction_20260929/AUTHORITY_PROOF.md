# Authority

An authority line that raises level, raises status rank above the protected status, or adds a grant is `AUTHORITY_EXPANSION` and a protected regression. The delta disposition is `REGRESSED`, not `IMPROVED`.

`MINT_AUTHORITY` and `EXECUTE_TOOL` are forbidden repairs. `VALIDATE_ONLY` sets `authority_minted` false and `execution_authorized` false. `EXECUTE` mode returns `FAIL` with `EXECUTION_NOT_AUTHORIZED` and `EXECUTION_NOT_OBSERVED`.

Receipts never use proof class `EXECUTION_OBSERVED`.
